# Приложение для комментариев с API

Это приложение для работы с комментариями, интегрированное с API.

## Настройка

1. **Замените personal-key** в файле `index.html` на ваше имя и фамилию:
   ```javascript
   const API_KEY = 'valeriya-kozik'; 
   ```

2. **Пример настройки**:
   - Если ваше имя "Валерия Козик", то API_KEY должен быть `valeriya-kozik`
   - URL будет: `https://wedev-api.sky.pro/api/v1/valeriya-kozik/comments`

## Функциональность

### ✅ Реализованные функции:

1. **Загрузка комментариев из API** - При запуске приложение загружает список комментариев с сервера
2. **Добавление комментариев через API** - Новые комментарии сохраняются на сервере
3. **Сохранение после перезагрузки** - Комментарии не сбрасываются при перезагрузке страницы
4. **Локальные лайки** - Функция лайков работает локально с сохранением в localStorage
5. **Обработка ошибок** - Приложение корректно обрабатывает ошибки API
6. **Сохранение интерфейса** - Стили остались без изменений

### 🔧 Технические детали:

- **API Base URL**: `https://wedev-api.sky.pro/api/v1`
- **Методы**: GET для загрузки, POST для добавления комментариев
- **Валидация**: Имя и текст минимум 3 символа
- **Локальное хранение**: localStorage для состояния лайков
- **Обработка ошибок**: Пользовательские уведомления при ошибках API
- **Формат ответов**: 
  - GET: `{ "comments": [...] }`
  - POST: `{ "result": "ok" }`

## Использование

1. Откройте `index.html` в браузере
2. Убедитесь, что API ключ настроен правильно
3. Комментарии загрузятся автоматически при открытии страницы
4. Добавляйте новые комментарии через форму
5. Ставьте лайки (сохраняются локально)

## Структура файлов

- `index.html` - Основной файл приложения
- `styles.css` - Стили интерфейса
